# DoorLock

Продвинутая система блокировки дверей и блоков для серверов Minecraft. Плагин позволяет игрокам создавать уникальные физические ключи и запирать ими двери, люки и другие блоки.

Этот проект поддерживается и развивается **l1ratch**. В основе лежит код оригинального плагина [DoorLock](https://github.com/SJones-BWGY/DoorLock) от **_joones**.

## ✨ Особенности

- **🔑 Физические ключи**: Для открытия двери требуется специальный предмет-ключ с уникальным ID.
- **🛡️ Надежная защита**: Замки привязываются к координатам блока и сохраняются в локальной базе данных **SQLite**.
- **⚡ Высокая производительность**: Оптимизированная работа с БД, отсутствие лагов при взаимодействии.
- **🔧 Админ-инструменты**: Команды для выдачи ключей, блокираторов, дрелей, просмотра информации о замках и обхода защиты.
- **🌍 Полная локализация**: Все сообщения настраиваются через файлы `lang/*.yml`, а язык выбирается в `config.yml`.

## 📦 Установка

1. Скачайте `.jar` файл плагина.
2. Поместите его в папку `plugins` вашего сервера.
3. Перезапустите сервер.

## 🎮 Команды

Все команды доступны через основной алиас `/doorlock` или сокращенный `/dl`.

| Команда | Описание | Право |
|---|---|---|
| `/dl help` | Показать список команд | `doorlock.use` |
| `/dl unlock` | Снять замок с блока, на который вы смотрите | `doorlock.unlock` |
| `/dl info` | Показать информацию о замке/ключе и статистику БД | `doorlock.admin` |
| `/dl getkey [id]` | Получить новый ключ или копию существующего по ID | `doorlock.admin` |
| `/dl getlocker` | Получить инструмент "Блокиратор блоков" | `doorlock.admin` |
| `/dl getdrill` | Получить инструмент "Дверная дрель" | `doorlock.admin` |
| `/dl reload` | Перезагрузить конфигурацию и сообщения | `doorlock.admin` |
| `/dl update` | Проверить наличие обновлений | `doorlock.admin` |

## 👮 Права (Permissions)

| Право | Описание | По умолчанию |
|---|---|---|
| `doorlock.use` | Базовый доступ к командам (`help`) | ✅ Все |
| `doorlock.unlock` | Позволяет снимать свои замки командой `/dl unlock` | 🔶 OP |
| `doorlock.bypass` | Позволяет открывать любые двери без ключа | ❌ Никто |
| `doorlock.admin` | Полный доступ (включает `use`, `unlock` + админ команды). **НЕ включает** `bypass`! | 🔶 OP |

## 🛠 Крафты

Для создания ключа и инструментов используются стандартные рецепты (см. конфигурацию `config.yml` для включения/отключения).
